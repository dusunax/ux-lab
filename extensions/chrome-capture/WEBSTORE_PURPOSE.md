# Chrome Web Store - 전용 목적 & 권한 설명

## 1️⃣ 전용 목적 설명 (0/1,000)

```
Smart Screenshot Capture는 개발자와 디자이너가 개발 중 스크린샷을 촬영할 때 디버깅 도구나 개발자 UI가 방해가 되지 않도록 지정한 HTML 요소를 숨기고 깔끔한 스크린샷을 캡처하는 데 사용됩니다.

사용 사례:
- 개발 중 콘솔, 개발자 도구 UI 숨기기
- 테스트 도구나 디버그 바 제거
- 스크린샷에 민감한 정보나 내부 UI 숨기기
- 팀과 공유할 프로덕션 화면 캡처

이 익스텐션은 모든 데이터를 사용자의 브라우저에만 저장하며, 외부 서버로 전송하지 않습니다.
```

---

## 2️⃣ 권한별 사용 이유

### activeTab 권한
```
현재 활성 탭의 스크린샷을 캡처하기 위해 필요합니다.

사용자가 "현재 탭 캡처" 버튼을 클릭했을 때, 현재 보고 있는 웹페이지의 화면을 스크린샷으로 저장합니다. 이 권한은 사용자가 명시적으로 캡처 버튼을 클릭했을 때만 실행됩니다.
```

### scripting 권한
```
페이지의 HTML 요소를 숨기고 표시하기 위해 필요합니다.

사용자가 입력한 CSS 선택자(예: button, .navbar, #modal)에 해당하는 요소에 스타일을 적용하여 visibility: hidden으로 숨기거나 복원합니다. 스크린샷 촬영 시에만 요소를 숨기며, 촬영 후 자동으로 원래 상태로 복원됩니다.
```

### tabs 권한
```
현재 활성 탭의 정보를 가져오기 위해 필요합니다.

스크린샷을 촬영할 대상 탭을 확인하고, 그 탭의 내용을 캡처하는 데 사용됩니다. 사용자가 "현재 탭 캡처" 버튼을 클릭했을 때만 실행됩니다.
```

---

## 3️⃣ 호스트 권한 사용 근거 (0/1,000)

```
이 익스텐션은 특정 호스트 권한을 필요로 하지 않습니다. 모든 웹사이트에서 CSS 선택자 기반으로 요소를 숨기고 스크린샷을 캡처할 수 있습니다.
```

소스 코드는 다음 파일들로 구성됩니다:
- popup.html/js: 메인 UI와 로직
- options.html/js: 설정 페이지
- content.js: 페이지 요소 조작

- manifest.json: 익스텐션 설정

모든 코드는 투명하게 공개되어 있으며, 보안 검토를 위해 누구나 확인할 수 있습니다.
