# Chrome Web Store 스크린샷 가이드

> **크기**: 1280×800 px (PNG)
> **포맷**: 1280x800, 640x400 권장 (자동 스케일링)

---

## 📸 스크린샷 #1: 메인 UI - 요소 선택 화면

### 화면 구성
익스텐션 팝업을 열어서 CSS 선택자로 요소를 선택하는 모습

### 포함 요소
1. **팝업 헤더**
   - 익스텐션 이름: "Smart Screenshot Capture"
   - 로고/아이콘 표시

2. **숨길 요소 입력 섹션**
   - "숨길 요소" 레이블
   - CSS 선택자 입력창 (예시: `button` 입력됨)
   - "추가" 버튼 (활성화)

3. **선택된 요소 목록**
   - `button` 태그 표시
   - 각 항목의 우측에 X 버튼 (삭제)

4. **액션 버튼들**
   - "⛶ 현재 탭 캡처" 버튼 (주요 버튼, 강조됨)
   - "숨김요소 초기화" 버튼
   - "⚙️ 설정" 버튼 (우측 하단)

5. **테마**: 다크모드
   - 배경: #1F1F1F (어두운 회색)
   - 텍스트: 흰색
   - 강조색: #FFD700 (황금색)

### 촬영 팁
- 팝업 전체를 프레임에 담기
- 최소 2~3개의 선택자가 등록된 상태로 보이기
- 버튼이 명확하게 보이도록 촬영

## 📸 스크린샷 #2: 설정 페이지 - 다크모드

### 화면 구성
options.html 설정 페이지를 다크모드로 열은 모습

### 포함 요소
1. **페이지 헤더**
   - 제목: "⚙️ 설정"
   - 부제목: "Smart Screenshot Capture"

2. **설정 항목들**
   - 🌙 Dark Mode 토글
     - 상태: **ON (파란색)**
     - 라벨: "Dark Mode"
   
   - 🌍 Language 선택
     - 드롭다운: "한국어" 선택됨
     - 또는 "English" 선택 가능

3. **상태 메시지**
   - 설정 변경 후: "✓ 설정이 저장되었습니다" 표시

4. **시각 요소**
   - 배경: #1F1F1F (다크모드)
   - 강조색: #FFD700 (황금색)
   - 토글: 활성화된 파란색

### 촬영 팁
- Dark Mode 토글이 ON 상태인 것을 명확히 보이기
- 사용 가능한 언어 옵션들이 보이도록 드롭다운 살짝 열기 (선택사항)
- 설정 저장 메시지가 표시된 상태로 촬영 (선택사항)

## 📸 스크린샷 #3: 설정 페이지 - 라이트모드

### 화면 구성
options.html 설정 페이지를 라이트모드로 열은 모습

### 포함 요소
1. **페이지 헤더**
   - 제목: "⚙️ 설정"
   - 부제목: "Smart Screenshot Capture"

2. **설정 항목들**
   - 🌙 Dark Mode 토글
     - 상태: **OFF (회색)**
     - 라벨: "Dark Mode"
   
   - 🌍 Language 선택
     - 드롭다운: "English" 선택됨
     - 또는 "한국어" 선택 가능

3. **상태 메시지**
   - 설정 변경 후: "✓ Settings saved" 표시

4. **시각 요소**
   - 배경: 밝은 흰색/라이트 회색
   - 텍스트: 검은색/진한 회색
   - 토글: 비활성화된 회색

### 촬영 팁
- Dark Mode 토글이 OFF 상태인 것을 명확히 보이기
- 라이트모드의 밝은 색상이 드러나도록 촬영
- 두 가지 테마 옵션이 있다는 것을 표현

## 📸 스크린샷 #4: 실제 사용 예시 - GitHub PR 페이지 활용

### 화면 구성
GitHub의 실제 PR 페이지에서 익스텐션을 사용하는 모습

### 포함 요소
1. **브라우저 탭**
   - 여러 개의 탭 표시 (개발 중인 느낌)
   - 현재 탭: GitHub PR 페이지

2. **GitHub PR 페이지**
   - PR 제목, 설명 등 GitHub 콘텐츠
   - 여러 개의 버튼들이 보임
     - "Comment" 버튼
     - "Request changes" 버튼
     - 기타 액션 버튼들

3. **익스텐션 팝업**
   - 선택자: `button` 입력됨
   - 버튼 요소들이 빨간 테두리와 배경으로 하이라이트됨
     - 테두리: 2px solid #FF4444
     - 배경: rgba(255, 68, 68, 0.1)

4. **하이라이트된 요소들**
   - PR 페이지의 버튼들이 선명하게 빨간색으로 표시됨
   - 다른 요소들은 일반적으로 표시됨

### 촬영 팁
- GitHub 페이지가 배경으로 명확히 보이도록 배치
- 익스텐션 팝업이 화면의 우측 또는 상단에 위치
- 여러 버튼들이 빨간 테두리로 하이라이트된 모습이 눈에 띄도록
- 실제 사용 사례임을 명확히 표현

## 📸 스크린샷 촬영 순서

1. **로컬에서 익스텐션 로드**
   ```bash
   # Chrome에서 chrome://extensions 접속
   # "개발자 모드" 활성화
   # "압축해제된 확장 프로그램 로드" 클릭
   # extensions/chrome-capture 폴더 선택
   ```

2. **각 스크린샷 촬영**
   - Chrome DevTools (F12) 또는 Mac 스크린샷 도구 사용
   - 크기: 1280×800 px
   - 형식: PNG

3. **파일 저장**
   ```
   screenshot-1-main-ui.png
   screenshot-2-settings-dark.png
   screenshot-3-settings-light.png
   screenshot-4-github-example.png
   ```

## 📤 Web Store 업로드

각 스크린샷을 다음 위치에 업로드:

1. 스크린샷 #1 → "메인 UI - 요소 선택"
2. 스크린샷 #2 → "설정 페이지 - 다크모드"
3. 스크린샷 #3 → "설정 페이지 - 라이트모드"
