🔒Smart Screenshot Capture - 개인정보 보호 정책

마지막 업데이트: 2026년 8월 17일

📋개요

Smart Screenshot Capture ("익스텐션")는 사용자의 개인정보 보호를 최우선으로 생각합니다.

이 익스텐션은 로컬에서만 작동하며, 사용자의 데이터를 외부 서버로 전송하지 않습니다.

💾수집하는 정보

1. 저장하는 데이터

익스텐션은 브라우저의 localStorage에만 다음 정보를 저장합니다:

  • CSS 선택자 목록: 사용자가 입력한 숨길 요소의 선택자
  • 테마 설정: 다크/라이트 모드 선택
  • 언어 설정: 한국어/영어 선택

2. 전송되는 정보

없습니다. 이 익스텐션은 외부 서버나 제3자에게 어떤 정보도 전송하지 않습니다.

3. 로컬 스토리지만 사용

모든 데이터는 사용자의 브라우저에만 저장되며, 삭제 시 완전히 제거됩니다.

🔑권한 사용 정책

1. activeTab 권한

사용 목적: 현재 활성 탭의 화면을 캡처하기 위해

사용자가 "현재 탭 캡처" 버튼을 클릭했을 때, 현재 보고 있는 탭의 스크린샷을 만드는 데 필요합니다.

2. scripting 권한

사용 목적: 페이지의 요소를 숨기고 표시하기 위해

사용자가 입력한 CSS 선택자에 해당하는 요소에 visibility: hidden 스타일을 적용하여 숨기는 작업에 필요합니다.

3. storage 권한

사용 목적: 사용자 설정을 저장하기 위해

선택자 목록, 테마, 언어 설정을 브라우저의 localStorage에 저장하기 위해 필요합니다.

4. tabs 권한

사용 목적: 현재 활성 탭 정보를 가져오기 위해

스크린샷을 촬영할 탭을 확인하는 데 필요합니다.

🛡️데이터 보안

✅ 모든 처리는 클라이언트 측(로컬)에서만 진행됨

✅ 네트워크 요청 없음

✅ 외부 API 호출 없음

✅ 광고/추적 코드 없음

✅ 제3자 분석 도구 없음

🗑️사용자 데이터 삭제

사용자는 언제든지 다음 방법으로 저장된 데이터를 삭제할 수 있습니다:

  1. 익스텐션 팝업에서 "숨김요소 초기화" 버튼 클릭
  2. 브라우저 설정 → 캐시/쿠키 삭제
  3. 익스텐션 제거

📝정책 변경

이 정책은 예고 없이 변경될 수 있습니다. 변경 사항은 이 페이지에 반영됩니다.
