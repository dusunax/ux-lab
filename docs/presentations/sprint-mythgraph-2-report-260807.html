기술

기술 스택 & 구현 상세

프론트엔드: React Flow + Bloom 레이아웃

React Flow 라이브러리로 그래프 시각화. Zeus를 중심으로 동심원 배치 (Bloom 알고리즘, baseDistance=350px, ringDistanceIncrement=250px). fitView 반응형 동작으로 노드 개수 변경 시 자동 줌/팬 조정.

상태 관리: Apollo Client 3.9 + GraphQL 캐싱

listEntities (전체 그래프) + searchEntities (키워드 검색) 쿼리. Apollo 읽기 전용 배열 문제 해결 — 스프레드 연산자로 뮤테이션 가능하게 변환 (line 100: [...result.data.listEntities.edges]).

데이터베이스: Neo4j Aura + Full-text Search

Neo4j Aura Free (70+ 신화 엔티티). Full-text search 인덱스로 키워드 매칭. LIMIT 타입 오류 해결 — neo4j.int() 래퍼로 GraphQL 정수 변환 (resolvers.ts:255).

검증 & 품질: searchValidation.ts + 30+ 테스트

[Image #N] 패턴 감지/필터링, 엔티티 구조 검사 (id/name/type 필수), matchScore 범위 검증 (0-1). 유효/무효 엔티티, 빈 결과, 특수문자, GraphQL 오류 등 E2E 안정성 보증.
