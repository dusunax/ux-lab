스코프 조정 사유

❌ 벡터 기반 의미론적 검색 → ✅ 키워드 검색으로 변경

이유: 의미론적 검색은 LLM API 비용($50-300/월)이 발생하므로 Sprint 3 이후로 연기

• Vector search는 "king of gods" 같은 자연어 쿼리에 강점
• Keyword search도 엔티티 이름/설명 기반 매칭으로 충분한 UX 제공
• 비용과 가치를 고려해 단계적 구현 결정

❌ Spring 물리 엔진 → ✅ 정적 Bloom 레이아웃으로 변경

이유: 명시적 비즈니스 요구사항으로 spring 물리 애니메이션 제외

• 관계 시각화에는 정적 레이아웃이 더 직관적
• 모바일 반응성과 성능을 우선시
• 향후 필요시 React Flow animation API로 추가 가능

⏭️ 최단 경로 알고리즘 → Sprint 3 이월

이유: Foundation 완성 이후 탐색 기능으로 단계적 구현

• Sprint 2는 기본 시각화와 검색 완성에 집중
• Sprint 3에서 Myth/Event 스키마 추가 후 경로 계산 구현
• 관련 OQ-7 (알고리즘 선택) 승인 대기 중
