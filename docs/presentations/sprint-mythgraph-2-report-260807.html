Foundation 고도화 및 검색 기능 통합
Bloom 레이아웃 구현, 엣지 시각화 개선, 키워드 검색 UI 구축으로 그래프 인터랙션 완성

📊 주요 성과

  • Bloom 레이아웃 — Zeus 중심 동심원 배치로 신화 체계 시각화
  • 엣지 시각화 — 관계 라벨 및 화살표 마커로 명확성 확보
  • 키워드 검색 — Neo4j full-text index 기반 빠른 검색
  • 데이터 검증 — 30+ 유닛 테스트로 E2E 안정성 보장

스코프 조정 사유

❌ 벡터 검색 → ✅ 키워드 검색

이유: LLM API 비용($50-300/월) 절감 + MVP 빠른 완성

• Vector search는 Sprint 3 이후 비용-효과 검토 후 도입
• 엔티티 검색에는 keyword search도 충분한 UX 제공

❌ Spring 물리 → ✅ 정적 Bloom

이유: 명시적 비즈니스 요구사항 (UX 명확성 + 모바일 성능)

• 정적 레이아웃이 관계 시각화에 더 직관적
• 향후 필요시 React Flow animation API로 추가 가능

⏭️ 최단 경로 → Sprint 3 이월

이유: Foundation 완성 후 탐색 기능으로 단계적 구현
