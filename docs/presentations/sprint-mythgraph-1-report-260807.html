Architecture & Scope 결정

D-1Entity 라벨: Deity, Human, Monster, Place로 고정. 고전 분류 기준 따름.
D-2Myth/Event 노드 포함: YES. 신화 내러티브 계층 구조 필요.
D-3벡터 임베딩: Sprint 3+로 이연. 먼저 정확한 구조적 그래프 완성.
D-4Neo4j 분리: Production은 Aura Free, 개발은 Docker. 로컬 테스트 신속화.
D-5GraphQL-first: REST API 불필요. 모든 쿼리는 GraphQL 통합 제공.
D-6Source 추적: 각 정보마다 참고 문헌 기록. 학술적 신뢰도 확보.
