## MythGraph Sprint 2 OQ-8 & OQ-9 의사결정

**문서 작성:** 2026-08-07  
**버전:** 1.0  
**상태:** 의사결정 완료 (PM 검토 필요)

### OQ-8: 하이브리드 검색 가중치 — 최종 결정

**선택:** 키워드 50% + 벡터 50% (균형 결합)

**이유:**
- 응답시간 SLA 준수 가능 (p95 < 1.5초)
- 비용 효율적 (월 $100-150)
- 정확한 이름 검색(키워드) + 의미론적 이해(벡터) 모두 지원
- 향후 A/B 테스트로 최적화 경로 명확

**구현 일정:**
- Phase 1 (2일): 기초 하이브리드 검색 Resolver + 스코어 결합 로직
- Phase 2 (1일): 캐싱, 배치 임베딩, 응답시간 벤치마크
- Phase 3 (Sprint 2 후반): A/B 테스트 계획 및 실행

**주의사항:** 벡터 임베딩의 질이 검색 성능을 결정 → OQ-9 (높은 신뢰도 Seed 데이터)와 연계 필수

---

### OQ-9: Seed 데이터 확대 문헌 — 2단계 접근

**Phase 1 (Sprint 2 즉시):**
- 선택: Theoi Project + Perseus Digital Library
- 목표: 120 entities (현재 70개 → +50개)
- 신뢰도: ⭐⭐⭐⭐⭐ (높음)
- 일정: 1주 (수집 3일 + 정규화 2일 + 검증 2일)

**Phase 2 (Sprint 3 초반):**
- 후보: 한글 신화 백과사전 (신뢰도 검증 후)
- 목표: +30+ entities (총 150+)
- 의사결정 포인트: Phase 1 검증 결과 + 벡터 검색 품질 만족도

**이유:**
- Phase 1 (학술 자료): 높은 신뢰도, 관계 정보 풍부 → OQ-8 검색 성능 기초 확보
- Phase 2 (한글): 사용자 맥락 반영, 커버리지 확대 → 단계별 검증으로 리스크 최소화

**데이터 검증 프로세스:**
1. 자동 검증: 중복, 고아 entity, 관계 무결성 체크
2. 인적 검증: PM(신화학 정확성) + Backend(스키마 준수)

---

### 상호 영향

**OQ-8 ← OQ-9:** 벡터 임베딩의 질은 Seed 데이터에 의존. Phase 1에서 신뢰도 높은 자료(학술)로 시작하면 검색 정확도 보장.

**OQ-9 → OQ-8:** A/B 테스트 결과로 최적 가중치 결정. 사용자 피드백(선택률, 클릭률)이 최종 기준.

### 위험 요소

1. **OpenAI API 비용 초과** → 배치 임베딩, 캐싱으로 30% 절감
2. **응답시간 SLA 미충족** → Day 3 벤치마크, 병목 발견 시 즉시 최적화
3. **Seed 데이터 신뢰도 낮음** → 2단계 peer review (자동 + 인적)
4. **데이터 정규화 지연** → Day 1부터 병렬 진행, 스크립트 사전 준비
5. **A/B 테스트 신뢰도 낮음** → 최소 20개 테스트 쿼리, 10명 사용자 미리 선정
