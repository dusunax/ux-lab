## 생각의 흐름

```
SENSE ──▶ REFLEX (rules, 즉시) ──▶ motion/emotion 변경 (말하지 않음)
              │ salience ≥ 0.50
              ▼
          친구가 터피에게 건넨 말인가? (텍스트 · 이름 부르기 · 나한테 한 말)
              ├─ 예 · 엔진 jev ─▶ TypeSafe jev APPRAISE → EXPRESS + REPLY (약 1초)
              │                    └─ 말할 확률 ≥ 0.5 ─▶ 대답 모음에서 jev가 고른 한 줄
              │                         └─ 적합도 낮음(none·확률<0.3·확신<0.4) ─▶ 무료 LLM이 한 줄
              ├─ 예 · 엔진 무료 LLM, 또는 jev 키 없음·상한·실패 ─▶ 무료 LLM 1회 ─▶ 평가 → 표현 → say
              └─ 아니오 / 무료 예산 소진 / 실패 ─▶ 본능(instinct) + 말투 템플릿
                                                        ▼
                                  ACT: 감정은 1위, 동작은 확률대로 뽑기, 말할 확률 ≥ 0.5면 say
SELF tick (1s): 에너지 감소 · 25초 무입력이면 스스로 생각(본능) · 저전력이면 몸 말고 잠
```

- **반사(reflex)** 는 몸만 움직이고 말하지 않는다. 말과 화음은 숙고 단계의 몫이다.
- **본능(instinct)** 은 규칙으로 판단한다. LLM을 부르지 않는 신호(혼자 생각·데스크탑·허밍)와, 엔진이 실패하거나 예산을 다 썼을 때 쓴다.
- **기억** 은 오늘 대화 수와 최근 8줄. 혼잣말은 대화 기억에 넣지 않는다.

### 대화 창 — 언제 대답하나

말에 이름("터피야")이 있거나 **대화 중**일 때만 대답한다. 주변 말소리는 귀만 기울인다.

| 경우 | 대화 |
|---|---|
| 이름을 부르거나 콘솔에 글로 말 걸기 | **새로 시작** |
| 대화 중에 이름 없이 한 말, 터피가 말함 | 이어 가기 (60초 연장) |
| 60초 동안 주고받지 않음 | 끝 (조용함) |
| 시작하고 3분이 지남 | **무조건 끝** — 주변 말에 계속 대답하며 끝없이 이어지지 않게. 다시 이름을 부르면 새로 시작 |

- 마이크가 켜져 있고 대화 중이면 원형 화면 아래에 "듣는 중 · 42초"처럼 남은 시간이 나온다.
- 대화가 끝나면 로그에 "대화 끝 · 1분 20초 (조용함|최대 시간)"이 남는다.

### 말 끊기 — 생각 중에 다시 말하면

생각(무료 LLM·jev·대사 쓰기)하는 동안 마이크에 **말소리가 시작되면** 진행 중인 요청을 취소하고 생각을 버린다. 귀 기울이는 자세(perk)로 바꾸고 대화는 이어 간 뒤, 새 말이 인식되면 그걸로 다시 판단한다. 기다리던 대기열도 비운다.

- 다른 엔진으로 내려가지 않는다(중단은 실패가 아니다). 취소 전에 보낸 요청의 비용·무료 횟수는 이미 쓴 것으로 센다.
- 에너지 기반 VAD라 기침·잡음에도 멈출 수 있다.
- whisper가 앞 구간을 인식하는 동안 들어온 구간은 버리지 않고, 가장 최근 것 하나만 남겨 이어서 인식한다(MIC 진단에 "더 최근 말이 와서 건너뜀"으로 보인다).

## 신호와 salience

| 신호 | 출처 | salience | 숙고 |
|------|------|----------|--------|
| 텍스트 대화 | 콘솔 입력 | 0.80 | ✅ LLM·jev |
| 이름 부르기 | 마이크 → whisper, "터피(야)"만 | 0.90 | ✅ LLM·jev |
| 대화 (나한테 한 말) | 마이크 → whisper, 이름 포함 또는 대화 중 | 0.80 | ✅ LLM·jev |
| 대화 (주변 말소리) | 마이크 → whisper, 그 외 | 0.35 | 반사만 · 내용은 로그·기억·LLM 어디에도 남기지 않음 |
| 허밍 | 마이크 — 음정 1.2초 지속 | 0.55 | ✅ 본능 |
| 큰 소리 | 마이크 — peak > -10dBFS | 0.30 | 반사만 |
| 자리 복귀 | 유휴 해제·화면 잠금 해제 (10분↑ 부재) | 0.60 | ✅ 본능 |
| 시간 | 정각 (00~04시만 숙고) | 0.70 / 0.25 | 새벽만 · 본능 |
| 유휴 10분 | `powerMonitor` | 0.40 | 반사만 |
| 활성 앱 | 앱 이름만 (개발 앱이면 집중 자세) | 0.35 / 0.20 | 반사만 · 판단 state로 전달 |

생각하는 동안(LLM 대기) 들어온 반사 신호는 로그만 남기고 몸을 바꾸지 않는다.

## 판단 계약 — jev 형식 타입 안전 질문

[`src/main/brain/decide/questions.ts`](../src/main/brain/decide/questions.ts) · [`mind.ts`](../src/main/brain/mind.ts)

[TypeSafe jev](https://docs.typesafe.ai/api)의 choice·noul·score와 같은 모양이다. 질문 정의 하나에서 요청 JSON, 응답 타입, 검증이 함께 나온다.

```ts
export const APPRAISE = defineQuestions({
  concern: noul('친구의 몸이나 마음이 걱정되는 상황인가'),
  joy: noul('친구에게 반갑거나 기쁜 일인가'),
  curiosity: noul('터피가 더 알고 싶어 궁금해지는가'),
});
export const EXPRESS = defineQuestions({
  emotion: choice(EMOTIONS, '앞의 평가를 바탕으로 감정', { ... }),
  motion: choice(MOTIONS, '감정을 표현할 동작', { ... }),
  intensity: score('반응의 세기', '무덤덤하다', '격하게 반응한다'),
  speak: noul('지금 친구에게 말을 걸어야 하는가'),
});
export const MIND = defineQuestions({ ...APPRAISE, ...EXPRESS });
type MindAnswers = Answers<typeof MIND>; // emotion.choice: Emotion, emotion.probabilities: Record<Emotion, number> …
```

- 응답: choice `{choice, probabilities, confidence}` · noul `{noul}` · score `{score}`. jev score는 0 ~ (단계 수 − 1)이라 0~1로 맞춘다.
- `parseAnswers`가 확률을 정규화하고 선택을 확률 1위로 맞춘다. LLM이 choice를 한 겹 더 감싸 보내도(실측 nemotron) 벗겨서 받는다. 하나라도 계약을 어기면 본능으로 대체한다.
- **무료 LLM**은 MIND 전체와 `say`를 JSON 하나로 한 번에 쓴다. 위에서부터 쓰므로 평가가 표현에 반영된다. 프롬프트에는 질문 정의에서 만든 응답 예시를 넣는다.
- **jev**는 질문이 독립이라(실측: concern 0.77인데 emotion calm) APPRAISE 답을 `state.appraisal`에 넣어 EXPRESS를 따로 묻는다. 시스템 프롬프트가 없어 페르소나는 `state.character`로 넘긴다.
- **선택**: 감정은 확률 1위, 동작은 확률대로 뽑는다. 1위 확률의 30% 미만 후보는 뺀다(실측에서 bounce .50에 나머지가 .07씩 퍼져 신난 상태에 자는 자세가 뽑혔다).
- 콘솔 DECISION 패널에 평가·감정·동작 확률 막대가 나온다. 본능 판단 뒤에는 마지막 LLM 판단을 흐리게 남긴다.

## jev 대답 모음 — "화났어?"와 "화났어."

[`src/main/brain/lines.ts`](../src/main/brain/lines.ts)

jev는 글을 쓰지 못하므로, 터피 말투 문장 181개(24자 이내)를 두고 두 번째 호출에서 `REPLY` choice로 고르게 한다. 보기마다 `{ when, say }`이고 jev는 when을 보고 고른다.

| 친구의 말 | 고르는 묶음 | 터피 |
|---|---|---|
| "화났어?" — 터피에게 묻는 말 | `ask.angry` | 나 안 화났어. 걱정 마. |
| "화났어." — 친구 자신의 상태 | `feel.angry` | 화났구나. 이유 말해 줘, 질문? |
| "내일 날씨 어때?" — 내용을 직접 답해야 함 | `none` | → 무료 LLM이 직접 쓴다 |

- 졸려·배고파·심심해·괜찮아·피곤해·아파·기분 좋아·무서워·외로워·바빠도 묻는 말(`ask.*`)과 상태(`feel.*`)로 짝을 나눠 두었다.
- 적합도가 낮으면(`none`, 확률 < 0.3, 확신 < 0.4) 무료 LLM에게 넘긴다. 무료 LLM도 안 되면 말투 템플릿.
- 실측(모음 103개 때, OpenRouter 경유 jev): 위로 0.69 · 축하 0.77 · 인사 0.93으로 모음 문장을 골랐고, 날씨 질문은 `none` 0.80.
- 문장을 늘리면 jev 입력 토큰(비용)도 늘어난다. 테스트가 24자 제한과 보기 255개 한도를 확인한다.

## 엔진·비용·키

엔진은 콘솔 상단에서 `무료 LLM` / `jev · 유료`를 고른다. 선택과 하루 사용량은 기억에 남아 재시작해도 이어지고, 자정에 0으로 돌아간다.

### 무료 LLM

- openrouter-proxy 경유. `:free` 모델과 `openrouter/free`만 호출한다(유료 과금 방지).
- OpenRouter 무료 등급은 하루 요청 수가 제한돼서, LLM은 친구가 건넨 말에만 쓰고 하루 40회(`MAIN_VITE_FREE_DAILY_BUDGET`) 예산을 센다.
- 호출당 요청은 1번이다. 모델 폴백은 proxy가 한다(main #82 404 폴백, #83 `openrouter/free` 최종 폴백·주간 점검). 여기서도 여러 모델을 돌면 proxy 폴백과 곱해져 한도를 몇 배로 쓴다. 기본 순서는 `nvidia/nemotron-3-super-120b-a12b:free` → `openrouter/free`, 실패한 모델은 쉬게 한다(404/403 6시간, 429 10분). `MAIN_VITE_FREE_MODELS`로 덮어쓴다.
- `response_format: json_object` + `provider.require_parameters`로 JSON 모드를 지원하는 무료 모델만 고른다.

### jev (TypeSafe)

- [TypeSafe API](https://docs.typesafe.ai/api) `POST https://api.typesafe.ai/v1/systemone`, `jev-latest`를 직접 부른다(console.typesafe.ai 크레딧).
- 응답에 비용이 없어 `usage.input_tokens × $0.042/1M`(출력 무료)으로 계산해 날짜별로 더한다. 메시지당 약 $0.0005(대답 181개 기준 추정), 하루 상한 `MAIN_VITE_JEV_DAILY_USD`(기본 $0.05 ≈ 95개 메시지)를 넘으면 무료 LLM으로 내려간다.
- 키가 없거나 거부(401/403)·실패해도 무료 LLM으로 내려간다.

### TypeSafe 키

- 콘솔의 "TypeSafe 키"에 붙여 넣으면 Electron `safeStorage`(macOS 키체인 기반)로 암호화해 `~/Library/Application Support/Tuffy/typesafe.key`에 저장한다.
- 빌드 결과물에 들어가지 않고, 저장한 값을 화면(renderer)으로 돌려보내지 않는다. 개발 중에는 실행 환경의 `TYPESAFE_API_KEY`도 읽는다.

## 반응 속도와 생각하는 모습

| 경로 | 반응까지 (2026-10-05 실측) | 비용 |
|---|---|---|
| 본능 (자리 복귀·새벽 등) | 즉시 | 0 |
| jev, 대답 모음에서 고름 | **0.81초** | 메시지당 약 $0.0005 |
| jev, 적합도 낮음 → 무료 LLM | 몸 약 1초, 말은 LLM 응답 뒤 | jev + 무료 1회 |
| 무료 LLM | 8~15초 | 0 (하루 40회 예산) |

- 몸(감정·동작·화음)과 말은 판단 직후 바로 나간다. 콘솔 사고 로그의 타자 효과는 기다리지 않는다(이전 구조는 jev 1초 + 대사 4초 + 타자 효과 대기 3초 ≈ 8초).
- **생각하는 모습**: LLM을 기다리는 동안 생각 동작(think)과 생각 점이 돌고, 화면 아래에 "생각 중 · · ·"가 흐른다.
- jev 대답의 적합도가 낮아 무료 LLM이 말을 쓰면, 몸이 먼저 반응해 1.2초 보인 뒤 생각 동작으로 기다리고, 말이 도착하면 반응 동작으로 돌아와 말한다(화음은 한 번만).

## 음성 인식

- 로컬 whisper.cpp(`whisper-server`, 127.0.0.1:8178)를 마이크를 켤 때 띄운다. 음성은 기기 밖으로 나가지 않는다.
- 콘솔 **MIC 진단 패널**: 입력 장치·샘플레이트, 실시간 레벨과 판단 기준선(음정 -45 / 말소리 -42 / 큰 소리 -10dB), VAD 상태, 최근 whisper 원문과 판정. 원문은 저장하지 않는다.
- **진짜 목소리만 보내기** (실측: 타자 소리가 구간으로 잘려 whisper가 "시청해주셔서 감사합니다"를 지어냄)
  - 말소리 기준은 조용한 순간의 소음 바닥 + 12dB로 따라 올라간다(최소 -42dB). 실측: 방 소음 -46dB → 기준 -34dB.
  - 구간은 음정(모음)이 잡힌 조각이 2번 연달아(약 0.26초) 나와야 시작한다. 타자·팬처럼 음정 없는 소리는 구간도, "말 끊기"도 일으키지 않는다.
  - 끝날 때 음정 조각이 30% 이상·0.3초 이상이어야 whisper로 보낸다.
  - 실측: 타자 소리(초당 약 7타) → whisper로 간 구간 0, 목소리 → 정확히 인식.
  - 작게 말하면 기준을 못 넘을 수 있다. MIC 진단에 "소음 → 말소리 기준"이 나오고 기준선도 따라 움직인다.
- **whisper 환각 걸러내기**: 유튜브·방송 자막 말투("시청해주셔서 감사합니다", "다음 영상에서 만나요", "구독과 좋아요", "MBC 뉴스 ○○○입니다" 등), 감탄·채움 소리, 같은 말 반복을 버린다. "이 영상 재밌더라", "좋아요" 같은 일상 문장은 남긴다. MIC 진단에 버린 이유가 나온다.
- 음정이 길게 이어진 구간은 whisper 결과로 판정한다. 이름을 부르면 말, 아니면 허밍 — whisper가 허밍에서도 그럴듯한 문장을 높은 신뢰도로 지어내기 때문이다(실측: "투데이 이슈 톡", "장인물").
- 실제 마이크에서 "터피야"가 "터키야"로 자주 들려, 호격 조사가 붙은 "터키야/터키아"도 이름으로 본다. whisper에는 `--prompt "등장인물: 터피"`를 준다(이름으로 끝나는 프롬프트는 문장 앞 호칭을 지워 버린다).
- 앱 안 STT 지연은 약 1.3~1.6초(M4, 1.5~4.5초 발화). temperature fallback(`-nf`)을 끄면서 4초대에서 줄었다. whisper가 처리 중이면 새 구간은 최근 것 하나만 남겨 이어서 인식한다.

## 알려진 제약과 실측 메모

- 활성 앱 감지는 macOS만 지원한다 (`lsappinfo`, 별도 권한 불필요, 앱 이름만).
- 음성 구간은 에너지 기반 VAD로 자른다. 시끄러운 환경에서는 구간이 길어질 수 있다. 녹음은 deprecated된 `ScriptProcessorNode`를 쓴다(AudioWorklet 전환 여지).
- 무료 라우터는 JSON 모드 없이는 추론형 모델을 골라 사고 과정을 본문에 늘어놓다 끊긴다(실측 4000토큰 중 3970 추론, finish=length). 작은 모델(실측 lfm-2.5 2.6B)은 계약을 어길 수 있어 본능으로 대체된다.
- 2026-10-04 혼자 생각하는 틱이 25초마다 LLM을 불러 무료 한도를 소진한 것으로 보인다(이후 모든 무료 모델이 404). 그래서 자동·반복 신호는 본능으로만 판단한다.
- 로그인할 때 자동 실행은 아직 없다. 필요하면 시스템 설정 → 일반 → 로그인 항목에 Tuffy.app을 추가한다.
