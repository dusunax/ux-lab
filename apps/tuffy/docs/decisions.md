|---|------|------|------|
| D1 | 입력 우선순위 | P1 텍스트 → P2 데스크탑 신호 → P3 마이크 | 2026-10-04 |
| D2 | 뇌 엔진 | 하이브리드 — reflex(룰) + cortex(LLM) | 2026-10-04 |
| D3 | LLM 경로 | `apps/openrouter-proxy` `POST /api/chat` 재사용 | 2026-10-04 |
| D4 | 판단 구조 | jev 형식 타입 계약(`defineQuestions`) + 엔진 교체 가능. 평가 → 표현 순서 | 2026-10-05 |
| D5 | 판단 엔진 | 기본은 **무료 OpenRouter 모델**. jev(유료)는 콘솔에서 고를 때만 쓴다 | 2026-10-05 |
| D6 | 말(VOICE) | 무료 LLM은 판단과 같은 호출에서 대사를 쓴다. 혼잣말·본능은 말투 템플릿 | 2026-10-05 |
| D7 | 선택 방식 | 감정은 확률 1위, 동작은 확률대로 뽑기(1위의 30% 미만 제외) | 2026-10-05 |
| D8 | jev 모드 | 친구가 건넨 말만 jev 2회(평가 → 표현), 하루 $0.05 상한 넘으면 무료로 | 2026-10-05 |
| D9 | jev 경로 | OpenRouter가 아니라 **TypeSafe 직접 호출**(console.typesafe.ai 크레딧). 키는 콘솔에서 등록, safeStorage 암호화 | 2026-10-05 |
| D10 | jev 대답 | 대답 모음에서 jev가 고름. 적합도 낮으면(none·확률<0.3·확신<0.4) 무료 LLM | 2026-10-05 |
| D11 | 반응 속도 | 몸·말은 판단 직후 바로, 로그 타자 효과는 기다리지 않음. 말이 늦으면 몸 먼저, 기다리는 동안 생각 동작 | 2026-10-05 |
| D12 | 대화 창·말 끊기 | 대화는 이름·글로 시작, 주고받으면 60초 연장, 시작 3분 뒤 무조건 끝. 생각 중 말소리가 시작되면 요청 취소 후 듣기. 마이크 켜짐 + 대화 중엔 "듣는 중 · N초" 표시 | 2026-10-05 |
| D13 | 진짜 목소리만 | 말소리 기준 = 소음 바닥 + 12dB(최소 -42), 음정 조각 2연속으로 구간 시작, 음정 30%·0.3초 이상만 whisper로. 영상 자막 환각 문구는 패턴으로 버림 | 2026-10-05 |
